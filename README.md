This project provides powerful select components that extend [shadcn/ui](https://ui.shadcn.com/) with advanced features. It includes Multi-Async-Select for multiple selection with async data loading and Select Content Pro for enhanced content customization.

**Built with the latest version of Next.js and shadcn/ui.** [View Demo, Documentation & API Reference](https://shadcn-multi-async-select.vercel.app/)

## 🚀 Features

### Multi-Async-Select

- 🔄 **Async Data Loading** - Fetch options dynamically as users type
- ✅ **Multiple Selection** - Select multiple items with intuitive UI
- 🔍 **Advanced Search** - Filter options with built-in search functionality
- 🏷️ **Customizable Labels** - Display options with custom formatting
- 🌓 **Theme Support** - Seamless light/dark mode integration

### Select-Content-Pro

- 🔍 **Enhanced Search** - Powerful search with debounced input
- 🔢 **Group Support** - Organize options into logical groups
- ➕ **Create New Items** - Add new options on-the-fly
- 🎨 **Fully Customizable** - Extensive styling and behavior options
- 🧠 **Smart Filtering** - Custom filter functions for complex use cases
